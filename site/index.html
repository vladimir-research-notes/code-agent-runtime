Code Agent Runtime

An independent systems/research platform for the runtime infrastructure around coding agents: task setup, tools, permissions, execution, tracing, replay, scoring, regression comparison, and reports.

status: Milestones 0–14 complete — final hardening (the plan is finished)

Brief explanation

Modern coding agents need a runtime, not just a prompt. This project builds the controlled environment that makes coding-agent behavior reproducible, inspectable, and evaluable: versioned tasks, structured tools, permission policies, command execution, trace recording, replay, scoring, and reports.

Current test/result status

CPU-only tests pass (python3 -m pytest -q), including environment, hygiene-scanner, task-format, tool, runtime, tracing, replay, sandbox, scoring, eval, regression/flakiness, LLM-adapter, and importer tests (the adapter and importer are tested entirely offline — no API key, no network). The runtime suite drives the scripted agent from failing tests to passing end to end and confirms the null mock agent leaves it failing; the tracing/replay suites assert a run reconstructs faithfully from its trace; the sandbox suite asserts blocked-vs-allowed and secret redaction. The scoring suite unit-tests every scorer and the suite runner produces a real multi-agent baseline; the regression suite asserts the improved/regressed/unchanged/flaky buckets on synthetic agent versions and that re-running the real suite yields zero flaky keys. The importer suite asserts an external run round-trips to the same verdict and that verify mode catches a forged passing claim a broken change carries — see Results. A guard asserts the committed tree is clean, and a release-readiness test asserts the repository passes every required final-hardening check (source compiles, hygiene/no-secrets/no-large-artifacts, docs and website consistency, README quality, reproducibility) and that each check fails on a deliberately broken input.

Open questions / limitations

The runtime enforces a sandbox policy (path/command/network gating, runtime/output caps) and redacts credential-shaped output on every agent tool call, but this is not a production-grade jail: command matching is by program name, network enforcement is a heuristic denylist, and there is no process/namespace isolation. Scoring now produces real verdicts, but a passing test command is evidence, not proof, of correctness and the task set is small — this is not a benchmark leaderboard. See Limitations, Evals, and Sandboxing.
