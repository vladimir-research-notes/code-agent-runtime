Current implementation status

Milestones 0–12 are complete: package scaffold, CLI, docs skeleton, this website, packaging, CPU-only tests, an environment check and repository hygiene scanner, a versioned task format (schema, loader, example tasks, and tasks CLI), a tool registry with seven structured core tools (and a tools CLI), a local runtime state machine that drives mock and scripted agents over a task (workspace preparation, tool gating, test execution, and a run CLI), structured run tracing (a JSON trace schema, an opt-in recorder driven by the run loop, and run --trace), trace replay/debugging tooling (reconstruct a run from its trace and render a text summary or Markdown report, via trace show / trace report), permission policies and sandbox controls (allowed/denied paths, command allow/denylist, network flag, runtime/output caps, and a secret scanner, enforced by default with an unsafe probe agent demonstrating blocked-vs-allowed), scoring and evaluation reports (all four scoring methods plus a custom-scorer registry, a suite runner producing a JSON result, Markdown/HTML reports, and an eval CLI — with a real baseline in Results), and regression comparison and flakiness analysis (diff two result files into improved/regressed/unchanged/flaky/added/removed buckets, plus a rerun mode that re-runs the suite N times to flag non-deterministic keys, via eval compare / eval rerun), and an optional cost-controlled LLM adapter (a model-backed llm agent behind a hard pre-call budget guard, a response cache, transcript redaction, and a --dry-run cost preview — offline by default via a deterministic fake client, opt-in to a real Claude API run with --allow-paid), and a Claude Code trace importer (normalise an external, Claude-Code-like run into this runtime's trace format and score it with the same scorer — in verify mode by re-running the task's real test command, or in trust mode against the source's declared evidence — via the import CLI), and a reproducible case study (13 small but genuine tasks across all five categories, run by both baselines plus the sandbox probes, emitting a result CSV, Markdown/HTML reports, and one trace per run, via scripts/07_case_study.py and a new suite_to_csv exporter).
